# 路线图（M1–M10）

产品终局：**PM / 前后端 / QA 共用的研发工作台**。一条需求从发起到提测都在同一条 Session 里完成：出原型、开会评、生成和预览代码、内嵌浏览器测、连库看数据。

Pi Agent 提供内核模型（Session、Tools、事件）；DeepSeek Harness 提供后期扩展形态（Everything-is-a-Plugin）。本产品是 Web 工作台，不是 IDE 插件。

## 原则

1. **先闭环，再完善。** M3 用一个「待办列表」跑通全角色；M4 起把每个角色做到能真正干活。
2. **内核是 Session + Tools，不是先写插件框架。** 工具先挂在 Session 上；等 PM/Dev/QA 工具都真实存在后，M9 再收成 Plugin Registry。
3. **每个 M 都要有用户能看见的结果。** HTTPS、注册表不单独插在用户价值前面。

## 终局能力

```
需求 → PRD / 多页原型 → 评审批注
     → 前后端代码生成 / 平台内预览 / 调试
     → 提测 → 内嵌浏览器测试 / 缺陷回流
     → 平台内数据库浏览与查询
```

同一条 Session 贯穿全程；角色只是不同阶段调用的工具包。

## 里程碑

### M1 — 对话通道 ✅

流式聊天 + Docker 公网上线。证明 Harness Shell 和模型通道成立。

### M2 — Session 工作区 + Agent Loop

一个需求 = 一个项目 Session：有文件树、对话绑在项目上。模型进入工具循环，能读/写项目文件，而不只是聊天。

这是后面所有角色工具的根。没有 Session 和 Loop，原型、预览、测浏览器都是假的。

**验收：** 新建 Session → 对话中让模型创建/修改一个文件 → 文件树可见 → 刷新后 Session 还在。

### M3 — 全角色最小闭环（待办 Demo）

固定演示：PM 贴一句「做一个待办列表」→ 生成可点的 HTML 原型 → 生成对应前端页面并在工作台预览 → QA 在 iframe 里勾选一条。Session 状态可走：需求 → 原型 → 开发 → 提测。

只求故事成立，不求每个角色完善。后面扩展全部加在这条流水线上。

**验收：** 不打开外部 IDE，一个人能在平台里把待办 Demo 从需求点到「已提测」。

### M4 — Dev 工作台（预览 + 调试）

把当前 Session 的前端真正跑起来（不仅静态 HTML）：热更新预览、控制台、网络请求、运行时错误叠在预览上。前后端开发都在这个工作台里生成、预览、调试。

**验收：** 改一行前端代码，预览即时更新；预览里的 JS 报错能在工作台看到。

### M5 — 后端运行时 + 平台内数据库

Session 内能生成并运行 API；自带一份项目数据库（起步可用 SQLite）；工作台里浏览表、看行、跑只读查询。对应「数据库都可以在这个平台里访问」。

**验收：** 待办 Demo 的接口真实读写库；QA/Dev 不用离开平台就能看到表数据。

### M6 — PM 工作流完善

需求结构化、PRD、多页原型、评审批注（开会用：在原型上画、留评论、通过/驳回）。未通过评审不能进开发。

**验收：** 一条需求能产出 PRD + 可点击多页原型；评审意见留在 Session 里；驳回后开发阶段不可进入。

### M7 — QA 工作流完善

内嵌浏览器（操作页面、截图、失败现场），而不仅是预览 iframe。缺陷回流到同一条 Session，开发能对着失败步骤改。

**验收：** QA 在平台浏览器里点测待办；失败自动带截图/步骤回到 Session；Dev 能从该缺陷继续改代码。

### M8 — 角色协作

登录与角色（PM / 前端 / 后端 / QA）。同一 Session 多人进入，各看各的工具，状态机统一：需求中 → 评审中 → 开发中 → 提测 → 通过。

**验收：** 四个角色账号能同时打开同一 Session；权限挡住越权操作（QA 不能改评审结论，PM 不能直接改生产库）。

### M9 — Plugin Registry

把已经跑真的工具（原型、写文件、预览、查库、浏览器测……）收成统一插件协议：声明、注册、鉴权、事件。此后加「设计稿导入」「性能剖析」是新插件，不再改内核。

**验收：** 用协议再写一个无业务意义的 Hello 插件并能在 Session 里调用；现有 PM/Dev/QA 工具全部改为走注册表，行为不回退。

### M10 — 生产级

Auth 完善、HTTPS、审计日志、多项目隔离、备份。这是把 Demo 平台收成可给真实团队用的环境，不是新功能故事。

**验收：** HTTPS 访问；项目数据互不可见；关键操作（改文件、查库、提测）有审计。

## 刻意不做（直到对应 M）

| 想做的事 | 放到 |
|----------|------|
| 插件市场 / 第三方插件 | M9 |
| 真会评的多人会议（音视频） | 不进主路线；M6 用原型批注代替开会 |
| VS Code / Cursor 扩展 | 不做；本产品就是工作台 |
| 任意语言任意仓库的通用 IDE | 不做；先吃透 Session 内生成的项目 |
