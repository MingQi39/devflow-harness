# 需求说明：待办列表（Todo List）

## 1. 目标
做一个简洁好用的待办列表应用，用户可以快速记录每天的待办事项，并标记完成或删除。

## 2. 目标用户与场景
- 个人日常任务管理。
- 场景：打开页面即可看到全部待办；随时新增一条任务；做完后勾选完成；不需要的任务删除。

## 3. 核心功能

### 3.1 新增待办（add）
- 页面顶部提供输入框，输入任务内容。
- 支持点击「添加」按钮或按 Enter 键提交。
- 新任务默认状态为「未完成」，追加到列表末尾。
- 输入为空或仅空格时不允许添加（给出提示或按钮置灰）。
- 可选：限制单条内容长度（如 100 字）并做提示。

### 3.2 标记完成 / 取消完成（complete / check）
- 每条待办左侧有复选框（checkbox）。
- 勾选后该条变为「已完成」状态：文字加删除线、颜色变淡，并移到列表底部（已完成区域）。
- 再次点击可取消完成，恢复为未完成。
- 可选：顶部显示统计信息，例如「共 N 项，已完成 M 项」。

### 3.3 删除待办（delete）
- 每条待办右侧有删除按钮。
- 点击后从列表中移除该条。
- 可选：删除前二次确认（视实现复杂度决定，简单版可直接删除）。

### 3.4 列表展示
- 未完成项排在前面，已完成项排在后面。
- 列表为空时显示占位文案，例如「暂无待办，先添加一条吧」。

## 4. 非功能需求
- 单页应用，纯前端实现（HTML + CSS + JavaScript），无需后端。
- 界面简洁清爽，适配手机与桌面浏览器（响应式）。
- 操作即时反馈，无刷新。

## 5. 可选增强（本次可不做，先记录）
- 数据本地持久化（localStorage），刷新页面不丢失。
- 编辑已有待办内容。
- 全部完成 / 清除已完成。
- 按状态筛选（全部 / 未完成 / 已完成）。

## 6. 验收标准
1. 能在输入框输入内容并成功新增一条待办，Enter 与按钮均可提交。
2. 空输入无法新增。
3. 勾选复选框后该条显示为已完成样式，并可取消完成。
4. 点击删除按钮后该条从列表消失。
5. 列表为空时显示空状态提示。
